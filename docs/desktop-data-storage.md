# 应用数据路径与容量提示（2026-09-30）

状态：已实现，v3.2.2 正式发布中；实际结果见[发布专题](release-v3.2.2.md)，不修改已发布 v3.2.1 Tag。

- 容量拒绝提示展示数据盘或临时盘、动态计算的最低空闲 GiB 和当前空闲 GiB；向上取整需求、向下取整剩余，保留原容量门。
- 安装版 API 设置页和画布加载失败页可选择其他盘。目标需要现有数据体积加 10 GiB 安全余量；系统临时目录所在盘仍需至少 0.5 GiB，不承诺 C 盘完全零占用。
- 原 Electron profile 保留以延续登录、浏览器存储和路径引导配置；迁移应用 data/input/output/thumbnails/semantic-models 五类目录及随 data 保存的配置、数据库、备份。
- 原窗口保存/任务关闭门通过后安排重启；新进程在后端打开数据库前离线复制，逐文件 SHA-256、源目录一致性校验及落盘后切换引导指针。原数据不删除，失败保持旧路径，未完成副本不作为权威数据。
- 不覆盖已有目标；拒绝源目录的父子路径及数据内链接/特殊文件。迁移失败或中断可能保留 partial 副本，不自动清理；断开的数据盘不会被空目录替代。
- 用户独立设置的导出路径、第三方目录及 Chromium profile 不自动迁移；原绝对路径引用不做字符串替换。

验证使用系统临时目录合成数据，未读取用户历史数据库。迁移单元测试 8/8、容量门原生 SQLite 5/5、关闭保存 12/12、发布证据门 4/4、双平台打包契约 22/22、TypeScript、i18n、公开范围、能力与预算门通过；跨物理盘安装版迁移、大容量掉电及真实用户旧库仍需外部验收，不能称为通过。
