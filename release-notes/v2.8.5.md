# T8 Penguin Canvas v2.8.5

本版在贞贞的平价AI小屋视频来源中新增 FLUX 3 Video，并扩展既有 Hailuo TAB 的 Hailuo H3 Global 模型。实现严格依据最新版官方 API 文档与参考项目，不改变默认视频模型、默认渠道、旧 Hailuo/Seedance 行为或已有画布显式参数。

## Hailuo H3 Global

- 既有 Hailuo TAB 新增 `hailuo-h3-global-t2v`、`hailuo-h3-global-i2v`、`hailuo-h3-global-multi`；重复的模型名按官方目录还原为 T2V、I2V、Multi 三种模式。
- 国内与 Global Hailuo H3 均支持 5–15 秒和 768P/2K。T2V 使用提示词与比例；I2V 支持一张首帧和可选尾帧；Multi 最多接受 9 张图片、3 个视频、3 段音频。
- 三个 Global 模型均已完成真实提交、轮询、本地下载、SHA-256 与 FFprobe H.264 解码验证；Multi 实际使用图片、视频和音频三种素材。

## FLUX 3 Video

- 视频节点新增 `Flux3` TAB，完整收录国内/Global 的 T2V、I2V、V2V、Draft Enhance 共八个官方模型。
- 支持 5–20 秒、HD/FHD 和官方八种比例；I2V 接受 1–10 张关键帧，V2V 只接受一个 MP4，模式不匹配的素材会在付费提交前失败关闭。
- 普通模式可显式开启草稿、音频和 0–4 安全容忍度；未显式设置的可选字段不会提交。Draft Enhance 只接受同线路 `metadata.draft=true` 完成任务返回的真实 `draft_cache`，不会伪造或跨线路复用。
- Flux3 使用独立的提交、状态查询和重启恢复类型，结果继续通过受控本地物化链路保存；完成任务在本地下载校验期间不会丢失。

## 工作流与验证边界

- 保存三份 Hailuo H3 Global 和八份 Flux3 的逐模型无密钥工作流；图片、视频、音频上传节点按模式显式连接，Draft Enhance 示例保留空草稿缓存等待真实上游结果。
- 发布前 Node 定向与相邻回归 89/89、Electron 恢复 9/9、TypeScript、公开/RH/能力同步门及生产构建通过。
- 真实 Provider 已完成 7/11：Hailuo Global 三模型与 Flux3 国内 T2V/I2V/V2V/Draft Enhance 均生成有效本地 MP4；国内 T2V 返回非空草稿缓存并由国内 Draft Enhance 成功消费。
- 测试账户在第一条 Flux3 Global T2V 接受前返回 `insufficient_user_quota`，余额不足以完成预扣费，因此四个 Flux3 Global 模型没有生成任务，也不会在 Release notes 中冒充实测通过。补足额度后可从 Global T2V 继续，不重放七个已成功任务。
- API Key 只在一次性验证进程中使用；源码、工作流与脱敏报告不包含密钥、任务 ID、签名 URL 或原始 Provider 响应。
- 反馈用户安装环境、完整渠道质量矩阵、协作多端与安装升级证据按用户授权在发布后补录；延期不会被标记为已通过。
