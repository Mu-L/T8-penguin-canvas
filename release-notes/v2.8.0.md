# T8 Penguin Canvas v2.8.0

本版在不回退现有节点、模型和网络兼容能力的前提下，进一步修复 RunningHub 国内/海外 WebApp 站点识别，并加固 Provider 生成、流式持久化和结果下载链路。

## RunningHub 国内/海外 WebApp 自动识别

- 普通 RunningHub、RH 钱包、RH 工具、自定义 RH 应用和 RH 工具箱统一识别上游返回的站点归属/身份错误码；只有确认未创建付费任务时，才尝试另一个已配置站点。
- 修复 WebApp ID 在错误站点返回 HTTP 200 + `code=901` 且没有可识别错误文本时不回退的问题；支持 `423`、`802`、`806`、`807`、`811`、`901`、`1002`、`1004` 这组受限的身份、Key、WebApp 或任务归属错误。
- 参数校验、余额、并发、限流、超时、5xx、生成失败及其他结果不会自动重放，继续保持单次提交和费用安全边界；RH 工具编辑器会持久化实际解析出的 `cn` 或 `intl` 站点。
- 真实只读检查确认：海外 WebApp `2075149522166181890` 在 `.ai` 直接成功、没有回退；国内 WebApp `2084704734417612802` 从 `.ai` 收到 `901` 后只回退一次到 `.cn` 并成功。该验证没有创建付费任务。

## Provider 生成与下载稳定性

- 保留 v2.7.4 以来 Chromium 系统代理、TUN、VPN、IPv4/IPv6 首选链路、可信 Provider 结果安全下载、同一 taskId 恢复、RunningHub 禁止手写 `Host` 和后续全部功能，不以回退旧实现换取兼容。
- 只有同步 Seedream V5 Pro `/v1/images/generations` 使用五分钟响应总时限，其他 Provider 仍保持 90 秒通用默认。
- Creator 在线回复会立即持久化首个 SSE 片段，后续小片段有界合并并在完成或停止前冲刷，超过 256 个上游细片段仍保持文本逐字一致。
- seedance.nz 媒体上传默认采用 120 秒总时限和 30 秒空闲读取时限；只对明确 HTTP 429 重试，不重放超时、中止、连接不可用或 5xx 等结果不明确的上传。
