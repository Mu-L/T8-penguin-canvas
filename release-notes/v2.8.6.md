# T8 Penguin Canvas v2.8.6

本版新增 Seedream V5 Pro 图层分解，并进一步放宽、加速所有已完成生成结果的下载恢复。现有默认渠道、默认模型、已保存画布参数、旧节点和既有 Provider 协议保持不变。

## Seedream 分层

- 图像节点新增独立 `Seedream分层` TAB，精确接入 `seedream-v5-pro-layer-decomposition`；必须输入一张图片，提示词可选且最多 2,000 字符，支持 auto/1k/1.5k/2k 与 PNG/JPEG 输出。
- 后端同时读取官方 `content.image_urls` 和真实 Provider 返回的 `data.upstream.response.results[]`，优先保留数组原始顺序与重复输出槽；底图及最多 16 个图层逐项使用稳定任务/序号键落盘，任一输出缺失时都不会误报完成。
- 保存无密钥工作流 `docs/workflows/seedream-v5-pro-layer-decomposition.json`。真实联调在一次已接受任务的只读查询遇到 HTTP 500 后，只恢复原 taskId，最终下载并解码 7/7：一张 1024×1024 底图和六张带透明通道的图层。

## 已完成结果下载恢复

- 图像、视频、音频、Suno 附件及 RunningHub 的已完成结果统一采用 0/500/1500ms 快速重试；系统代理、TUN、VPN、慢首包、连接中断或 HTTP 408/425/429/5xx 时，可切换到拥有独立时间预算的 DNS 固定安全回源。
- 物化调度窗口放宽到 5 分钟，单路径尝试最多 2 分钟，连接建立 8 秒即快速切路，连续 30 秒没有数据才判定停滞；全部恢复失败时以 1 秒建议继续查询同一任务。
- 恢复只执行只读状态查询和结果下载，始终保留原 taskId，不会自动重放生成 POST、创建替代任务或造成重复扣费。用户取消和 HTTP 404 不会触发回退。
- SSRF/私网地址拦截、跨源敏感头剥离、真实接收字节上限、媒体签名、原子落盘与持久化校验继续生效；部分下载切路前会清空暂存内容，避免拼接损坏文件。
