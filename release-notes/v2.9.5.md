# T8 Penguin Canvas v2.9.5

本版新增 FashVSR 视频超分节点，并为 Seedance 2.5 六个 Standard 国内/Global 模型加入官方 `native1080p` 分辨率选项。默认渠道、默认模型、旧画布显式参数和历史工作流保持不变。

## 新增

- 独立节点 `FashVSR 视频超分`，精确模型 ID 为 `FashVSR_video_upscale`。
- 节点只接受一个 480P、3–15 秒视频；提交前使用随包 FFprobe 校验，提交体只包含 `model` 与 `metadata.video_url`。
- 成功后沿原任务查询、下载到本地、验证并持久化，不通过重新提交生成请求来恢复结果。
- Seedance 2.5 国内/Global 的 Standard T2V、I2V、Multi 六模型增加 `native1080p`；不增加文档未声明的 `native4k`。
- 新增无密钥工作流 `docs/workflows/fashvsr-video-upscale.json`；既有六份 Seedance 2.5 工作流继续使用 720p 安全默认。

## 验证

- FashVSR 只提交一次真实任务并成功：854×480、H.264、3.208008 秒输入，得到 1920×1024、H.264、3.208333 秒输出；下载、FFprobe 和全量解码通过。
- Seedance 2.5 `native1080p` 按官方 API 文档与固定参考实现确认；依费用边界未创建高价付费任务。
- FashVSR、Seedance 2.5 及相邻回归 68/68，TypeScript、能力同步、JSON/Node 语法与生产构建已通过开发验证；正式 Electron/NSIS 与自动更新门禁必须在固定源码发布流程中全部通过。

## 完整保留

- MiniMax Music3 提示词增强器已在 v2.9.3 正式发布，不是待发布能力。本版继续完整包含其节点、工作流、官方固定 Skill 快照、1,022 个上游文件、18 个风格族索引、1,000 个模板及 SOURCE/NOTICE/manifest。
