# T8 Penguin Canvas v2.7.3

本版补齐贞贞的平价AI小屋 Hailuo H3 三种视频模式，并修复资源库图片、视频、音频作为生成节点上游素材时的格式识别与上传问题。

## 新增

- 视频节点 Hailuo TAB 新增：
  - `hailuo-h3-t2v`：文生视频，2K，5–15 秒。
  - `hailuo-h3-i2v`：首帧图生视频，可选尾帧，2K，5–15 秒。
  - `hailuo-h3-multi`：多模态参考视频，支持受限数量的图片、MP4 视频与 MP3/WAV 音频。
- 新增三份可导入工作流：`hailuo-h3-t2v`、`hailuo-h3-i2v`、`hailuo-h3-multi`。
- 创作 Agent、zcanvas CLI、Skill 与后端能力目录同步公开 Hailuo H3 模型、参数和约束。

## 修复

- 修复从资源库拖进画布的图片、视频、音频作为上游参考素材时，因为 `/api/resources/file/<id>` 没有扩展名而被误判格式、误走图片限定校验或上传失败的问题。
- 拖拽资源会保留原始文件名、MIME 与大小提示；后端恢复资源库真实文件名，并以文件魔数作为最终格式依据。
- 平价AI小屋共享上传链路支持经过验证的图像、视频和音频；图像专用入口仍保持图片限定，非媒体文件不会被放行。
- 音频节点接收资源库无扩展名地址时，会依据原始文件名和响应 MIME 恢复正确音频扩展名。
