# 贞贞的无限画布 v2.6.4

本版重点增加 RH 视频能力层和视频抠像，并集中修复 MOV 预览、FFmpeg/FFprobe、Story 成片合成与视频落盘可靠性问题。

## RH 视频能力层

- 上传素材和输出素材为视频时，左侧新增“抠像”入口；调用 RH 工具箱 `video-removebg-v1`，支持进度、停止和失败反馈。
- 抠像结果不会覆盖原视频，而是生成新的输出素材节点；本地文件、RH capability、工具 ID、任务 ID 和来源节点会随画布持久保存。
- 内置 RH 发布清单新增 `video.cutout` 能力、视频抠像分类与真实 WebApp 字段映射；发布前及安装包 post-build 会校验工具和 WebApp 标记确实进入用户包。

## MOV、FFmpeg 与视频合成

- MOV/ProRes 等浏览器不直接支持的视频会生成 H.264/AAC MP4 兼容预览，原始素材地址保持不变，上传/输出节点可以正常显示、播放并截取当前帧。
- 补强 FFmpeg/FFprobe 路径解析和 Windows 运行时兜底；正式包同时携带权威 FFmpeg/FFprobe sidecar 与兼容 FFmpeg，并在 post-build 中执行实际编码和 JSON 探针。
- RH 抠像、MOV 预览、资产索引、LLM 视频抽帧/压缩、Story 和剪辑合成的本地 FFmpeg/FFprobe 进程统一经过后端 FIFO 队列，避免 Windows 同时启动多个原生进程时发生 `0xC0000005` 崩溃；API 生成任务仍可并发提交。
- Story/视频剪辑的合成、临时文件原子提交、失败诊断、恢复和花屏防护得到修复；完成状态必须对应可验证的本地视频，不再把未成功落盘冒充成片。

## Story、循环与模型

- Story 进入准备资产阶段不再自动开始全部生成；只生成缺失项且不覆盖用户上传/资产库素材。单项重生成可并发并显示独立状态，资产支持删除。
- 角色资产使用白底脸部特写与三视图约束，服装资产减少人物和场景污染；视频生成、成片导出和刷新后的阶段状态继续修复。
- 并联循环修复派生节点实体 ID 与执行映射，避免重复实体导致画布崩溃。
- LLM / Vision 新增 `gpt-5.6-luna`、`kimi-k3`、`gemini-3.6-flash`，并支持 Custom 自定义模型名。

## 发布与验证边界

- 发布前执行 RH、FFmpeg/MOV、Story、循环、LLM、视频合成、TypeScript、公开源码和生产构建门禁；Electron/NSIS 正式打包只触发一次。
- 公开源码继续排除 `skill.md`、`roadmap.md`、`local-private/**`、测试 Key、缓存、外部参考项目和本地归档。
- F8–F10 的真实双设备、三个隔离客户端、公共 HTTPS/TLS/SNI、红队与负载证据仍待补。按用户 2026-07-23 的明确授权，v2.6.4 只在证据清单完全不存在且绑定固定 40 位 source commit 时使用 `owner-approved-post-release-v2.6.4` 一次性延期；延期不会把任何证据检查标记为通过。
