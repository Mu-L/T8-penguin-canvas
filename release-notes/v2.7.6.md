# T8 Penguin Canvas v2.7.6

本版新增“剧本大师”专业工作台，并修复 VPN、TUN、透明代理或 CDN 改写远程响应声明长度时，已生成媒体可能无法保存的问题。

## 新增

- 新增 `script-master` 剧本大师节点，支持 TXT、Markdown、Fountain 与 JSON 剧本文本的确定性解析，保留原文位置、稳定人物/场景/镜头 ID，并提供独立专业工作台。
- 图片、视频与音频素材分别使用稳定、删除后不重排的 `@imageN`、`@videoN`、`@audioN` 引用；同一镜头可以编译多张参考图、多段视频与多段音频，不再收缩为单个素材。
- 多轨时间线统一使用整数帧和半开区间，支持镜头、对白、配乐、环境声与音效编排，并输出 PromptPack、ReferenceBindingManifest、AudioPlan、EDL 与反向映射。
- 支持叙事、电商、广告、MV、纪录/访谈、口播/教学六类创作质检；Story、导演分镜、Seedance、音频和视频剪辑下游必须先预览 CanvasPatch，再由用户明确确认写入，不会自动启动付费生成。

## 修复

- 远程媒体安全下载不再把 `Content-Length` 当作最终文件尺寸，也不会仅因响应头声明长度与实际响应体不一致而失败；这可兼容 VPN、代理或 CDN 解压、转码、分块及响应头重写。
- 大小限制仍按实际接收字节执行，并继续保留连接/空闲/总时限、空媒体、HTML/JSON 错误页、归档、跨媒体类型伪装、私网目标和不安全落盘路径拒绝。

- 剧本大师聚焦回归 30/30、相邻 CanvasPatch / Story / Director / VideoTimeline / WorkflowDoctor 回归 226/226 通过；VPN 声明长度聚焦回归 30/30、相邻系统网络与 Provider 回归 111/111 通过。
- TypeScript 与能力目录检查通过，能力目录覆盖 31 项公开动作、200 项运行时条目和 71/71 个节点。
