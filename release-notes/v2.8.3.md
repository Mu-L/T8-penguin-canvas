# T8 Penguin Canvas v2.8.3

本版新增 MV 音乐大师节点，把歌曲、人设、风格、歌词、分镜图、分段视频和最终成片组织为可确认、可恢复、可逐段重做的完整制作链。默认渠道和旧画布数据不变，默认 LLM 仍为贞贞的平价AI小屋 `bytedance/doubao-seed-2.1-pro`。

## MV 音乐大师

- 新增 `mv-music-master` 节点与八阶段全屏工作台：素材授权、音频分析与分段、导演设置、视觉圣经/逐段 Prompt、分镜图候选、分段视频候选、原曲合成与 QC、正式交付。
- 每段实际音频严格限制为 5.000–14.990 秒，15 秒失败关闭；LRC/SRT/人工时间为歌词权威，ASR 只提供时间证据，不改写歌词，也不从完整句子中间切开。
- 长歌词和多镜头按有界批次调用 LLM；PromptPack 固定英文视觉描述并保留原始歌词，禁止正向可见文字和声音字段复述歌词。用户可逐段审阅、拒绝、重新生成并明确采纳分镜图和视频候选。
- 图片可选贞贞AI工坊 literal GPT Image 2 或贞贞平价小屋 G2；视频可选 Seedance 2.0 与经目录证明可用的 MiniMax/Hailuo H3。UI 选择别名和实际上游 canonical 模型同时持久化，旧画布不会被静默迁移。
- 最终成片先固化版本化 EDL，再丢弃所有生成视频音轨并只映射一次完整原曲；物理校验不冒充主观 QC，只有前台 1x 无拖动完整播放后才能生成 QC 与交付回执。

## 安全、停止与恢复

- 主歌曲、人设、风格、运镜和候选资产先物化为项目资产；每次付费请求前重新读取真实字节并校验 SHA-256，授权与稳定 submission key 同时绑定渠道、canonical 模型、任务类型、请求体和素材摘要。
- Provider 返回必须匹配已批准的 provider/model/taskType；不匹配或缺少可信恢复证据会持久化为阻断状态，不会自动轮询成成功、物化、采纳或交付。
- 无 taskId 的不明确提交标记为 `ambiguous`，批量流程不会自动重放可能已计费的写请求。父级 STOP 会贯穿 LLM、图片/视频提交与查询、可信下载和本地合成，迟到结果不能覆盖停止状态。
- 上游素材或采纳版本变化会撤销旧下游视频、分镜、EDL、QC 与交付输出，避免旧成片被误用。

## 验证与发布边界

- MV 分段、Prompt 合同、候选审阅/采纳、Provider 身份、停止/恢复、安全媒体与 FFmpeg 单音轨合成专项和相邻回归通过；能力目录同步为 75/75 节点、0 公共缺口，TypeScript、公开源码检查、RH 工具箱清单和生产构建纳入固定发布提交门。
- 小规模真实链路验证了默认 LLM、单图、单视频、真实下载与完整原曲单音轨合成；其中旧检查点不满足最新 PromptPack 合同，当前验证器按设计失败关闭，没有伪报为艺术质量或最新合同通过。
- 反馈用户安装环境、完整渠道/模型质量矩阵、协作多端和安装升级证据按用户授权在发布后补录；延期不会被标记为已通过。
- Electron/NSIS、私有后端加密、运行时归档、post-build、provenance、sealed recovery、三项自动更新资产、固定 Tag 与 Latest 只由固定 source commit 上的唯一正式发布流程生成并核验。
