# T8 Penguin Canvas v2.6.9

本版正式把画布内 Creator Agent、Agent Control、zcanvas CLI 与 Codex Skill 合并为同一套可扩展创作能力，同时整理模型来源并继续提高代理网络下的生成结果下载稳定性。

## Creator Agent 与本地 Agent 闭环

- 左侧画布快捷条新增轻量 AI 入口，打开清晰的大字号流式对话面板；支持新建对话、历史会话、文字及图像/视频/音频附件。
- 一句话即可开始剧本、角色、资产、分镜、生成和成片规划；未开工时提供三个灵感入口，每轮回复后提供恰好三个可点击的下一步建议。
- 支持引用当前选区或指定节点、定位素材、把已验证素材发送到画布，以及从脚本逐步形成资产提案、镜头表、分镜、Prompt 包、候选审阅和交付清单。
- 画布写入、节点运行和交付均经过明确审批与新鲜度检查；使用真实 revision、Run/NodeRun、素材哈希和本地产物证据，不把计划或聊天回复冒充执行成功。
- Agent Control、zcanvas CLI 和打包内 Codex Skill 共用同一能力图、模型目录、协议与权限边界，后续能力更新可由统一清单同步。

## 模型与平台

- 图像、视频、LLM 和 Story 将“贞贞的AI工坊”与“贞贞的平价AI小屋”按真实来源分开显示，旧画布会按已保存模型恢复正确平台。
- 平价AI小屋新增 `zhenzhen-image-nb-pro`、`zhenzhen-image-nb-2`、`zhenzhen-image-nb-2-lite`；香蕉2默认使用完整 `zhenzhen-image-nb-2`。
- 视频 Veo TAB 新增 `zhenzhen-video-v31-lite`，并按官方能力约束时长、分辨率、比例和参考素材。
- 模型注意事项移动到放置栏之前；API 设置与节点中的平台名称统一为“贞贞的平价AI小屋”。

## 稳定性与兼容

- 图片、视频、音频、3D 与 RH 等生成结果继续共用安全远程转存链路；代理、TUN、VPN 或 Fake-IP 切换后刷新连接并重试下载，不会重复提交生成任务。
- 开发后端统一使用 Electron Node ABI，避免 `better-sqlite3` 原生依赖不匹配；Windows 启动窗口中文日志使用 UTF-8。
- 工作流医生继续默认关闭，由用户按需开启；模型来源与运行前提示使用更白话的说明。
- Creator Agent 与 zcanvas 的本地凭据只保存在本机安全存储中，公开源码、安装包日志和能力清单不包含 API Key。

## 发布边界

- 本次 Electron/NSIS 正式打包只执行一次，并限制 CPU 资源占用；不执行 FFmpeg 媒体转码或额外冷启动压力测试。
- 用户已明确授权先发布、后补真实 Provider、协作多端、安装升级和完整远端回下载证据；延期不会把缺失证据标记为通过。
