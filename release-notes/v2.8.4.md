# T8 Penguin Canvas v2.8.4

本版新增 Seedance 2.5 Standard 系列的独立核心节点和视频节点入口，严格同步贞贞的平价AI小屋最新官方 API 文档。默认视频模型、Seedance 2.0、已有画布显式参数及其他渠道均保持不变。

## Seedance 2.5

- 新增独立 `seedance25` 节点，并在既有视频节点加入 `Seedance 2.5` TAB；两个入口复用同一套 `/v1/videos` 提交、查询、受控上传和结果本地物化链路。
- 一个节点完整收录六个精确模型：国内/Global 的 `standard-t2v`、`standard-i2v` 与 `standard-multi`，模型名不会经过 Seedance 2.0 档位推断或改写。
- T2V 只接受必填 Prompt；I2V 接受 1–2 张依次作为首帧/可选尾帧的图片，Prompt 可选；Multi 要求 Prompt 与至少一个素材，最多 30 图、10 视频、10 音频且总计不超过 50 个。
- 新建节点和六份配套工作流按当前官方文档默认 5 秒、720p；时长支持 4–30 秒或智能 `-1`，分辨率支持 480p、720p、1080p、2k、4k。旧画布已保存的显式值不迁移。

## 素材与付费前安全门

- 图片仅接受 JPG/JPEG/PNG/WEBP 且单项不超过 30MB；视频仅接受 MP4、音频仅接受 MP3/WAV，单项不超过 50MB。
- Provider 在付费任务提交前使用随包 FFprobe 读取真实媒体：每段音频或视频必须为 2–30 秒，全部音视频参考的合计时长不得超过 30 秒。
- 视频总节点不再把 Seedance 2.5 音频引用截断为三个，完整支持官方上限 10 个；请求失败不会自动重放可能已计费的写操作。
- 六份工作流不保存 API Key、任务 ID、签名 URL或 Provider 原始响应。

## 验证与发布边界

- Seedance 2.5 模型目录、缺省值、请求形状、自动时长、素材格式/时长/数量边界、双 UI 入口、六份工作流、Provider 安全与旧功能相邻回归通过；TypeScript、公开源码检查、76/76 节点能力同步和生产构建纳入固定发布提交门。
- 六个模型已有真实提交、轮询、下载与 FFprobe 解码的 6/6 脱敏证据；本轮文档刷新以零新付费任务完成真实中文文件名 MP4/WAV 本地物理预检。该证据不冒充完整渠道质量矩阵。
- 反馈用户安装环境、完整渠道/模型质量矩阵、协作多端和安装升级证据按用户授权在发布后补录；延期不会被标记为已通过。
- Electron/NSIS、私有后端加密、运行时归档、post-build、provenance、sealed recovery、三项自动更新资产、固定 Tag 与 Latest 只由固定 source commit 上的唯一正式发布流程生成并核验。
