# T8 Penguin Canvas v2.8.1

本版新增 Qwen Image 3.0 与 MiniMax H3 OW 模型，继续完善 MiniMax H3 提示词增强器，并修复部分用户在 RunningHub 海外站选项下查询 WebApp ID 失败的问题。默认渠道、默认模型和旧画布数据保持不变。

## Qwen Image 3.0 与 MiniMax H3 OW

- 图像节点新增 `Qwen Image` TAB，收录 8 个国内/Global、标准/Pro、T2I/I2I 模型；支持文档规定的自动尺寸、比例与 1K/2K、自定义 `W*H`、1–6 张输出、seed、负向提示词和提示词扩写，I2I 仅接收 1–3 张参考图。
- 视频节点既有 `Hailuo` TAB 新增 `minimax-h3-ow-t2v`、`minimax-h3-ow-r2v`、`minimax-h3-ow-i2v`，严格限制 5/10/15 秒、480p/720p、八种比例以及各模式的提示词与单图要求。
- 新增 11 份单模型工作流和 2 份配套并发工作流；并发工作流复用真实 Loop parallel 调度、预检、取消、克隆与结果聚合。
- 11 个模型均完成真实 Provider 提交、轮询、下载与媒体校验：8 张结果为可解码 1024×1024 PNG，3 个结果为 864×480、约 5.167 秒 H.264 MP4。凭据、任务 ID、签名 URL 和原始响应未写入源码或工作流。

## MiniMax H3 提示词增强器

- 同步 MiniMax H3 官方 Skill 的兼容/严格英文协议与 8 个场景写作预设；旧画布继续使用兼容协议和无预设，不迁移语言、渠道或模型。
- 既有“MV / 歌词贴字”预设补齐数字人 MV 规则：锁定用户歌词和实际声源，隔离人物/场景/字体参考，保持 H3 分段本地时间，并让每段拥有自足开场与可衔接末帧。
- 默认仍为“贞贞的平价AI小屋”与 `bytedance/doubao-seed-2.1-pro`；每次运行仍只发起一次 LLM 请求，节点不声称分析未提供的音频。

## RunningHub WebApp 只读双站查询

- `app-info` 明确作为无副作用的只读查询：所选站点返回任一非成功业务码或发生传输/解析失败时，会继续尝试另一套已配置站点凭据，不再猜测 `332` 等不透明业务码的含义。
- 普通 RunningHub、RH 钱包、RH 超市、自定义 RH 工具和 RH 工具箱共用该修复；前端访问本机 `/api/proxy/runninghub/app-info` 仍是隔离 API Key 和 CORS 的正常桌面端路径。
- 提交、上传、任务查询和取消继续使用窄回退分类器；`332` 不会触发付费路径重放，避免重复生成或重复扣费。
- 真实只读检查确认海外 WebApp `2075149522166181890` 可在 `.ai` 选项下直接返回 4 个字段；确定性回归同时覆盖 `.ai code=332` 后只回退一次到 `.cn` 并成功。
