# T8 Penguin Canvas v2.9.8

本版为贞贞的平价AI小屋补充 Grok 图像编辑和 Lyria / Flow Music 完整创作链路。现有 79 个节点、默认渠道、默认模型、旧画布、MiniMax Music3、FlashVSR、Seedance 2.5 `native1080p` 及 v2.9.7 项目数据库启动兼容修复全部保留。

## Grok Image 编辑

- 图像节点 Grok Image TAB 新增精确模型 `zhenzhen-image-gk-v2-edit`。
- 支持 1–3 张有序参考图、`n=1..10`、`auto` 与官方固定比例、1K/2K；不发送该合同未定义的 `quality`。
- 保存无凭据工作流 `docs/workflows/zhenzhen-image-gk-v2-edit.json`。

## Lyria / Flow Music

- 音频节点新增 Lyria TAB，固定上游请求模型为 `flowmusic`。
- 覆盖九种操作：`flowmusic-generation`、`flowmusic-lyrics`、`flowmusic-upload-audio`、`flowmusic-extend`、`flowmusic-replace`、`flowmusic-cover`、`flowmusic-stems`、`flowmusic-download-audio`、`flowmusic-video-clip`。
- 生成音频、歌词文本、音乐视频和 stems ZIP 分类型完整转存；原生 `clip_id` 随节点结果持久化，并可通过上游音频连接继续传递。
- 九份配套工作流均不保存 API Key、任务 ID或签名 URL。
