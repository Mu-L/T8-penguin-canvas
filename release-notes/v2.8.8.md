# T8 Penguin Canvas v2.8.8

本版新增独立的 MiniMax H3 官方提示词增强器，严格按贞贞的平价AI小屋最新版官方协议接入三种 Context IR 模型。默认渠道、默认模型、历史节点、已保存画布字段及既有 Provider 能力保持不变。

## MiniMax H3 官方提示词增强器

- 精确支持 `minmax-h3-context-ir-text`、`minmax-h3-context-ir-image` 与 `minmax-h3-context-ir-multimodal`，统一通过 `/v1/video/generations` 提交和查询，并读取非空 `result_text`。
- Text 模式只接受文本提示词，要求选择固定比例；Image 模式必须按顺序输入 1–2 张首尾帧图片，不发送比例并拒绝视频/音频；Multimodal 模式至少输入一种素材，最多接收 9 图、3 视频、3 音频，比例可省略、使用 adaptive 或固定值。
- 提示词严格限制为 1–7000 字符，目标时长为 4–15 秒；模型、枚举、输入类型和数量由前后端在付费提交前共同校验。
- 节点复用现有平价AI小屋凭据、停止、同任务恢复与运行追踪，不在画布、工作流或发布包中保存 API Key、taskId、签名 URL 或原始 Provider 响应。
- 配套提供三份无密钥工作流，可分别直接导入 Text、Image 与 Multimodal 模式。
