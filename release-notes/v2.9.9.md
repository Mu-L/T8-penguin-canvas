# T8 Penguin Canvas v2.9.9

本版新增 Hunyuan 3D、Grok 智能分割/区域编辑和 Grok Omni 低价视频能力。现有默认渠道、默认模型、旧画布、全部 81 个节点、MiniMax Music3、FlashVSR、Seedance 2.5、Lyria / Flow Music 及 v2.9.8 和更早功能全部保留。

## Hunyuan 3D

- 核心节点新增稳定的“3D”入口，节点内部采用可扩展 TAB 注册表，首个 TAB 固定为 `Hunyuan 3D`，后续可继续并列增加其他 3D 家族。
- 支持 `hunyuan3d-v3.1-text-to-3d` 和 `hunyuan3d-v3.1-image-to-3d`。
- 图生支持 1–8 张按正、左、右、后、上、下、左前、右前排列的有序视图，并支持面数、PBR 与 Normal/Geometry/Sketch。
- Provider 完成后继续下载并校验真实 GLB；只有本地持久化成功才完成节点，随后自动进入现有 3D 交互预览和下载节点。

## Grok 图像与视频

- 新增独立“Grok 分割编辑”节点：智能分割阶段保存 `image_id` 和对象列表，区域编辑阶段支持对象索引、矩形框或选区三种互斥方式。
- Grok Video TAB 新增 `zhenzhen-video-g-omni-flash-lowprice`，覆盖文本、首帧、参考图、参考视频四种模式。
- 视频支持 4/6/8/10 秒、720P/1080P/4K、16:9/9:16；参考图只接受 1 或 3 张，参考视频只接受 1 个且不发送时长字段。
- 保存 8 份无 API Key 配套工作流。
