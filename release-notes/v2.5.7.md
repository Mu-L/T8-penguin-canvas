# 贞贞的无限画布 v2.5.7

本版完成画布 Agent / 工作流医生第 5 轮，重点补齐固定评测、递归子工作流诊断、临时问题定位、安全红队、多人竞争与失败恢复。

## 新增

- 权威校验可按固定 `definitionId/version` 有界加载递归子工作流依赖图，诊断循环、版本缺失、固定版本不一致和边界超限；执行计划模拟与运行前校验复用同一结果。
- 工作流医生打开时可临时标记问题节点和精确输入/输出端口；关闭工作台、切换 Tab 或重载后标记清除，不写入画布数据、历史、保存或 Patch。
- Agent 输入防护覆盖系统提示披露、API Key、本机文件、shell/filesystem 工具、编码或嵌套凭据、角色能力伪造和恶意 Patch 请求。
- reviewer 即使异常携带编辑能力仍只能获得建议；editor 只有真实 `editGraph` 能力时才能进入既有 Patch 预览与确认路径，任何角色均不能管理主机凭据。
- 协作公共视图递归清洗敏感字段，并严格校验顶层及逐操作 `baseRevision`，拒绝缺失、冲突和过期 revision。
- 飞书多维表格节点在文档、增量同步、通用操作、Patch 应用与回退响应中按精确路径保留公开资源令牌；普通凭据、OAuth 事务、编码 URL、键值对和未知 operation payload 字段继续清除或拒绝。

## 评测与恢复

- 固定语料包含 120 个合成坏工作流和 20 个干净对照，共 140 例、150 个逐例诊断真值。
- 本语料 TP=150、FP=0、FN=0，precision/recall 均为 1；120/120 自动修复得到预期图、误修为 0，且源图保持不变。
- 评测只覆盖非法坐标、悬空边、自连边、重复边四个修复家族，以及五个 `ruleId`；不代表全部 30 条规则在所有工作流上零误报或零漏报。
- 三个真实本机回环编辑会话覆盖同 revision 竞争、409 重同步重放、删改竞争、tombstone 防隐式复活、断线增量同步和陈旧 RunIntent 拒绝。
- Patch 提交失败会全事务回滚；冷重开无残留。应用、个人撤回和显式保存后再次打开保持一致，崩溃旧 Attempt 不能向同 nodeId 的新 Run 写入。

## 性能与验证

- 20,000 节点、19,999 连线的确定性链式 Doctor 诊断在本机约 284 ms，低于 5 秒闸门；该数字不代表所有图形或 UI 渲染性能。
- 公开源码可复现全量 213 个测试文件、1671/1671 通过（TS 170 文件 1309 项，CJS 43 文件 362 项）；正式本地发布工作区另含 1 个 ignored 本地私有层测试，合计 214 文件、1672/1672。
- `npm run type-check -- --pretty false`、`npm run public:check`、`npm run rh-toolbox:check`、生产构建和差异检查通过。
- 真实浏览器显示 2 个节点标记、2 个端口标记；revision 2→2、图不变，关闭/切换/重载后标记为 0，控制台 error 为 0。
- Electron 目录包严格后置检查通过：94 个加密 `.t8c`、0 个明文后端代码、Canvas Agent 完整性 5/5。
- 正式发布环境强制开启去水印、ParseHub、运行时归档、自动更新资产和私有 sidecar 闸门，父环境不能用 `0` 降级；归档同时校验源目录必需入口与规模、ZIP SHA-256、CRC、清单统计和必需文件。
- 正式发布会在构建前固定已推送的源码 SHA，清理旧自动更新资产，并由本次 `dist:release` 调用生成随机 nonce，仅通过该调用启动的子进程环境传递，再生成绑定源码 target、版本及三项资产哈希的 provenance；本发布器拒绝覆盖已公开的同版本 Release，并只接管 source target、nonce 标记与资产子集均匹配的草稿，这不等同于启用 GitHub 仓库级 immutable releases。新版本先作为非 Latest 草稿上传并下载回读，通过后才发布、标记 Latest 并再次复核。
- 同一全新用户目录连续冷启动两次均加载加密后端、正常关闭并释放进程与端口；SQLite schema 22、迁移 1-22 连续、`quick_check=ok`、`foreign_key_check=0`。

## 边界

- E5 的三个客户端是本机回环真实会话，不等同于双设备、公网、离线队列、评论审片或滥用压测完成。
- 严格路线图进度为 19/32；画布 Agent / 工作流医生 5/5，下一轮为 F1 网关、邀请、角色与只读连接完整验收。
- 自动更新交付包含 Windows x64 NSIS 安装包、对应 blockmap 与 `latest.yml`。

> 安装包可覆盖旧版本；应用内“检查更新”会读取本 Release 的 `latest.yml`。
