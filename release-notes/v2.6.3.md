# 贞贞的无限画布 v2.6.3

本版集中修复近期升级后出现的画布复制、Alt 拖动复制、并行生成、组/子工作流端口体检等回归，同时补齐即梦 CLI、自定义并联循环、GPT Image 2 参数和视频当前帧截图。

## 画布交互与并行执行

- 恢复节点复制粘贴与 Alt 拖动复制；快捷键在节点内部控件获得焦点时仍由画布正确接管，系统剪贴板存在旧图片时也优先使用刚复制的节点。
- 运行启动只串行保护短暂的准备阶段，不再等待前一个生成任务完成；不同节点可同时生成，并分别绑定不可串用的执行令牌、RunContext 与停止状态。
- 组、子工作流、随机路由及动态端口按实际节点实例解析，工作流医生不再把合法组出口误报为“未知节点类型”；真实未知类型仍继续阻断。
- 开发启动器先等待后端健康再启动前端和浏览器，避免端口清理与 Windows 批处理解析问题导致白屏或启动失败。

## 循环、模型与创作入口

- 循环器新增“并联循环（自定义）”：主素材决定任务数，文本、图片、视频、音频可分别选择按顺序每次取一个，或固定复用指定素材；原串联和并联模式保持不变。
- GPT Image 2 标准路径新增质量与内容审查选项，均默认 Auto；参数只发送到支持该能力的标准 GPT Image 2 路由。
- 即梦 CLI 帮助统一显示登录、退出、更新命令和当前支持版本 1.4.14；图像生成新增 Seedream 5.0 Pro，并同步 2026-07-21 CLI 的图片尺寸、视频多模态与模型命名兼容。
- Grok OAuth Agent 恢复清晰可见的“登录 / 绑定”入口，未授权状态可直接完成登录，而不是只显示错误。

## 视频素材与错误诊断

- 上传节点和输出节点的视频预览新增“当前帧”：按当前播放或拖动位置截取 PNG，保存到 T8 输出目录，并在右侧创建图片输出节点。
- SD2.0 / seedance.nz 本地素材地址优先按受控 T8 文件处理；远程上传失败时反馈更明确的来源、网络或安全校验原因。
- 本版延续 v2.6.2 的生成结果去重、真实下载诊断和敏感信息脱敏规则。

## 发布与验证边界

- 已完成定向回归、TypeScript 检查、真实 FFmpeg 当前帧截图验证和生产构建；正式 Electron/NSIS 仅允许执行一次。
- 公开源码继续排除 `skill.md`、`roadmap.md`、`local-private/**`、测试 Key、缓存、外部参考项目和本地归档。
- F8–F10 的真实双设备、三个隔离客户端、公共 HTTPS/TLS/SNI、红队与负载证据仍待补。按用户 2026-07-23 的明确授权，v2.6.3 只在证据清单完全不存在且绑定固定 40 位 source commit 时使用 `owner-approved-post-release-v2.6.3` 一次性延期；延期不会把任何证据检查标记为通过。
