# T8 Penguin Canvas v2.7.7

本版新增 MiniMax H3 提示词增强器，并放大“剧本大师”专业工作台的文字与操作密度，解决高分辨率界面中文字过小、控件拥挤的问题。

## 新增

- 无限画布新增 `minimax-h3-prompt-enhancer` 节点，参考 MiniMax H3 ComfyUI 实现，支持 T2VA、I2VA、FL2VA、L2VA 与 Ref2VA，以及严格、均衡、创意三档增强、中文/英文输出和官方/模板模式。
- 默认渠道继续使用“贞贞的平价AI小屋”，默认模型继续使用 `bytedance/doubao-seed-2.1-pro`；同时支持贞贞工坊和当前设置中全部已启用、具备 LLM 能力的扩展渠道。
- I2VA/L2VA 固定接收 1 张图片，FL2VA 按连线顺序接收首尾 2 张图片；Ref2VA 支持最多 9 张图片、3 个完整视频，视频总时长不超过 15 秒，单媒体上限 50MB。
- 节点已接入共享 Schema、精确端口、Run/NodeRun/Attempt 生命周期、凭据体检、Provider/模型权威和 Creator Agent `create.script` 能力。

## 界面改进

- 剧本大师全屏工作台的辅助文字、表单、按钮、区块标题和镜头标题整体放大，素材行、三栏宽度与时间线轨道同步增加间距。
- 顶部操作区和时间线工具栏支持安全横向滚动；窄窗口保留最小编辑宽度，不再挤压、堆叠或覆盖操作文字。

## 安全与兼容边界

- 已保存的 Provider 或模型失效时明确失败，不静默切换渠道或模型；API Key 只从全局设置读取。
- MiniMax H3 付费生成请求不自动重放。扩展渠道接收完整视频原始字节，保留视频音轨；默认平价AI小屋继续使用受控文件上传。
- 用户已明确授权先发布，真实 Provider、协作多端、安装升级与外部环境证据按 `owner-approved-post-release-v2.7.7` 在发布后补录；延期项目不会标记为已通过。

## 发布前验证

- H3/RunIntent/Agent/端口与执行权威回归 41/41，扩展 Provider/完整视频/体检/Workflow Doctor 相邻回归 83/83。
- 剧本大师节点与可读性布局定向回归 5/5；隔离浏览器在 2048×1024、100% 缩放下确认可见文字和控件阈值满足要求，三栏、顶部、时间线与状态栏无重叠。
- TypeScript、能力同步、公开发布面、开发工作树门与生产前端构建通过；正式 Electron/NSIS、自动更新资产和 GitHub Release 由本次发布流程生成并核验。
