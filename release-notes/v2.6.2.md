# 贞贞的无限画布 v2.6.2

本版新增 Story 全自动制片节点，并集中修复异步生成重复落盘、图片任务完成却未返回本地素材，以及运行配置提示难以理解等创作中断问题。

## Story 全自动制片

- 新增 Story 节点和六步工作台：剧本与风格、确认镜头、准备资产、合成提示词、生成视频、成片导出。
- 镜头可编辑、增删、复制、拆分、合并、重排和锁定；角色、场景、道具、服装、声音资产支持自动识别、电脑上传、上游素材、资产库选图、单项 AI 生成和一键补齐。
- 语言模型复用现有 LLM 选项，图像模型复用 GPT Image 2 TAB，视频模型复用 SD2.0 与扩展 Provider；选择会同步到实际分析、资产生成、视频生成和物化后的导演分镜台，不会只改变界面显示。
- 完成镜头确认后自动进入准备资产，资产齐备后自动进入合成提示词；底部主按钮与顶部阶段保持一致。
- 分层提示词保留全局风格、角色身份、场景、动作、镜头、光线、声音、必须出现与禁止项；已完成资产和视频可恢复、跳过或仅重试失败项，最终复用现有 VideoEdit/FFmpeg 顺序合成。

## 生成可靠性与错误反馈

- SD2.0、视频、图像、音频、RunningHub 与 RH 工具的异步轮询改为单飞；相同 Provider、任务和输出索引使用稳定文件名，避免一次任务重复保存几十份相同素材。
- 图片任务只有在结果成功下载并保存到本机后才会报告完成；兼容更多常见 Provider 输出结构，并对临时网络错误最多重试三次。
- 下载失败会反馈真实、可行动的原因，包括 DNS/Fake-IP/代理、超时、HTTP 状态、连接中断、TLS、非图片/超限内容、磁盘空间、目录权限或上游空结果；签名 URL、Token 和 Key 继续脱敏。
- 缺少 API Key 或本地服务时，执行前体检改为白话说明缺少什么、在哪里设置；内部 capability/credential 代码默认收进技术详情。

## 发布与验证边界

- Story、运行体检、异步去重和图片输出下载链路已通过专项回归、类型检查和生产构建；本版不会把未执行的真实付费完整 Story 制片冒充为已验证。
- 版本由 `package.json` 统一注入 Web、Electron 与后端；公开源码继续排除 `local-private/**`、私有扩展实现、测试 Key、缓存、外部参考项目和维护者文档。
- 自动更新交付包含 Windows x64 NSIS 安装包、对应 blockmap 与 `latest.yml`；本版只触发一次正式 Electron/NSIS 构建。
- F8–F10 的双设备、三个隔离客户端、公共 HTTPS/TLS/SNI、红队与负载证据仍未补齐。按用户 2026-07-22 的明确授权，v2.6.2 仅在证据清单完全不存在且绑定固定 source commit 时使用一次性“先发布、后补证据”延期；这不会把任何外部证据检查标记为通过。
