# T8 Penguin Canvas v2.9.3

本版在完整保留 v2.9.2 启动、目录、主题、媒体调度与跨画布后台运行优化的基础上，正式加入 MiniMax Music3 提示词增强器。既有节点、模型、默认渠道、用户画布、工作流与 Provider 协议均不回退。

## MiniMax Music3 提示词增强器

- 新增 `minimax-music3-prompt-enhancer` 纯文本节点，服务于音乐生成前的歌词、结构、曲风、编曲、演唱与 Caption 策划，不直接生成音频。
- 歌词支持 AUTO、生成、逐字保留、定域润色与纯音乐模式；可编辑全曲、同名全部段落或指定第 N 个段落。
- 支持结构预设、语言、拍号、目标时长、BPM、调性、Caption 字数、创作限制与随机种子。
- 输出最终歌词、Music 3 Caption、标准 Payload 与脱敏报告，可连接标准文本和元数据下游节点。

## 运行与安全边界

- 默认私有语义模式不会把原始歌词行发送到 Caption 阶段；疑似 API Key、不安全控制标签和超限输入会在提交前失败关闭。
- 多阶段请求使用持久 child attempt 与 submission ledger；不明确的 Provider 提交不会自动重放，避免重复计费。
- STOP、后台跨画布运行、节点实体身份、revision CAS 与旧画布持久化行为继续沿用 v2.9.2 安全边界。
