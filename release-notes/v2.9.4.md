# T8 Penguin Canvas v2.9.4

本版在完整保留 v2.9.3 MiniMax Music3 提示词增强器及官方固定 Skill、v2.9.2 启动优化和全部历史能力的基础上，新增两个贞贞的平价AI小屋 LLM，并集中修复用户提交的 ParseHub、FFmpeg 与 ComfyUI 工作流问题。既有节点、模型、默认渠道、用户画布、工作流与 Provider 协议均不回退。

## LLM / Vision 新模型

- 贞贞的平价AI小屋新增 `zhenzhen/gk-4.6` 与 `qwen/qwen3.8-max`。
- 两个模型进入统一权威 allowlist，LLM / Vision 下拉框、后端校验、RunIntent 与能力目录使用同一来源。
- 两个模型的非流式与 SSE 流式真实 API 最小请求共 4/4 通过。
- LLM / Vision 默认仍为 `bytedance/doubao-seed-2.0-mini`；MiniMax H3、Seedance 2.0 与 MiniMax Music3 提示词增强器默认仍为 `bytedance/doubao-seed-2.1-pro`，旧画布显式模型不迁移。

## GitHub Issues 修复

- [#12](https://github.com/T8mars/T8-penguin-canvas/issues/12)：ParseHub 或挂载目录中不同子目录的同名 `0.mp4` / `0.png` 现在使用包含受控来源片段的保存名，不再互相覆盖。
- [#20](https://github.com/T8mars/T8-penguin-canvas/issues/20)：FFmpeg 7 在视频结尾截帧返回 exit 0 但没有输出文件时，会在同一次只读任务中快速尝试安全回退时间，并要求非空文件才成功。
- [#21](https://github.com/T8mars/T8-penguin-canvas/issues/21)：ComfyUI 图像输入识别不再把 `scheduler` 等普通字段中的 `hed` 子串误判为 HED；只匹配独立 HED 字段或明确的 `HEDPreprocessor`。
- [#22](https://github.com/T8mars/T8-penguin-canvas/issues/22)：ComfyUI 应用制作器新增输出节点多选并贯通后端白名单；Seed 数字参数新增随机/固定切换。旧应用未保存白名单时继续兼容收集全部输出。
- [#23](https://github.com/T8mars/T8-penguin-canvas/issues/23)：ComfyUI 自动识别跳过由连线提供的宽高、Seed、文本、媒体、采样器和模型字段，不再用默认值覆盖链接。

## MiniMax Music3 保留确认

- `minimax-music3-prompt-enhancer` 节点、固定 `MiniMax-AI/MiniMax-Music3@91410fb657c007ae57c60df8240f5ece5be089c7` 官方 Skill 快照、1,022 个上游文件、18 个风格族索引、1,000 个模板、SOURCE/NOTICE/manifest 继续包含在安装包。
- Music3 默认渠道与模型仍为贞贞的平价AI小屋 `bytedance/doubao-seed-2.1-pro`，现有扩展 LLM 渠道、STOP、后台运行、持久 attempt 与不重放边界保持不变。
