# 贞贞的无限画布 v2.5.6

本版在保留 v2.5.5 Wan 2.7 Spicy 与 Dola Seedream 5.0 Pro 海外模型的基础上，完成画布 Agent / 工作流医生第 4 轮：接入运行中心权威证据、执行前只读体检和失败后诊断。

## 新增

- 工作流医生可引用持久化的 Run、NodeRun 与 Attempt，展示对应 Provider、模型、HTTP、requestId、轮询和规范化错误证据。
- 失败原因按平台、配置、网络和画布结构分类；缺少证据的字段保持未知，不从任意任务 ID、错误文本或历史记录猜测。
- 批量执行前新增只读体检，核对项目、画布、revision、节点范围、结构 digest、Provider 能力和可证实的成本信息；用户取消时不会调用 Provider。
- RunIntent 精确绑定 project / canvas / revision / run mode / target / requestId，幂等重试只接受完全等价内容，避免旧任务、错误目标或部分失败串写。
- reviewer 只获得解释与建议，editor 不能读取或修改主机 API Key；Agent 只看到当前已配置的能力，结构修复仍需预览和明确确认。

## 兼容

- v2.5.5 的 `wan-2.7-spicy-i2v`、`dola-seedream-5.0-pro-t2i` 与 `dola-seedream-5.0-pro-i2i` 保持不变。
- 旧画布继续默认国内 Seedream V5 Pro；未配置海外模型时不会自动切换到 Dola。
- 没有明确价格证据时，执行前体检只显示成本未知，不猜 Provider 调用次数或价格。

## 验证

- E4 聚焦前端 364/364、后端 160/160；全量 211 个测试文件、1653/1653 通过。
- `npm run type-check -- --pretty false`、`npm run public:check`、`npm run rh-toolbox:check` 与生产构建通过。
- 真实浏览器验证执行前体检与失败后诊断：诊断引用具体 Run / NodeRun / Attempt，并基于 HTTP 504、`ETIMEDOUT`、`providerCalled=false` 将测试失败归类为网络问题；浏览器控制台 error 为 0。
