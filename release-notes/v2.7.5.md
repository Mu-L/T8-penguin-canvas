# T8 Penguin Canvas v2.7.5

本版继续从生成成功率与画布稳定性出发，修复资源库/项目资产作为上游素材时没有转换为 Provider 可读取物理文件的问题，并处理画布随机 React #310、RunningHub 管理界面遮挡及节点操作栏缩放不一致。

## 修复

- 资源库、素材集与项目资产的图片、视频、音频会在 LLM、图像、视频、音频和 RunningHub 提交前统一解析为受控物理文件，不再把 `/api/resources/file/*` 或 `/api/project-assets/*/media` 当成 Provider 文件名直接提交。
- 有效媒体魔数可以纠正 CDN 返回的错误 MIME 子类型或文件扩展名；未知新编码可按可信 MIME、文件名或当前节点要求的媒体种类兼容，避免真实素材被误拦截。
- 继续拒绝 HTML/JSON 错误页、ZIP/归档、空文件、超限文件、跨媒体种类伪装、不可信远程目标和任意磁盘路径；不会因为兼容旧素材而开放越权读取。
- RunningHub 普通节点与 RH 工具箱统一识别所有 T8 受控媒体引用并在提交前上传真实字节；WebApp 站点显示继续跟随实际解析的国内站或海外站。
- RH 超市管理弹窗改为挂载到页面顶层，避免被画布悬浮 RUN / 关闭按钮遮挡。
- 修复切换或加载空画布时 Hook 数量变化触发的生产版 React #310。
- 缩小或放大画布时，选中节点顶部的 RUN / STOP / 关闭操作栏现在随节点同比缩放，并保持右上角锚定。

## 验证

- 素材解析、RunningHub 站点/上传、画布 Hook 顺序、操作栏缩放与代理安全日志聚焦回归 57/57 通过。
- TypeScript、公开发布面、RH 工具箱、能力目录和 Electron 发布门由固定发布提交上的唯一一次正式流程继续验证。

## 发布边界

- 本次正式 Electron / NSIS 包只构建一次，限制为 4 路并发并使用 BelowNormal 优先级，不运行 FFmpeg 转码压力任务。
- 用户已明确授权先发布，后补真实 Provider、协作多端与安装升级证据；延期项目不会提前标记为通过。
