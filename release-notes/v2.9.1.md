# T8 Penguin Canvas v2.9.1

本版在视频节点既有 Hailuo TAB 中补充三个 MiniMax H3 OW Fast 模型，并保存三份可直接导入的无密钥工作流。既有默认模型、默认渠道、历史节点、已保存画布字段以及 v2.9.0 和更早版本的全部能力保持不变。

## 新增模型与输入合同

- 新增 `minimax-h3-ow-ref2va-audio-drive-fast` 与 `minimax-h3-ow-fl2va-audio-drive-fast`：每次任务必须且只能输入 1 张图片和 1 段音频，拒绝视频，提示词可选；Provider 只向 `metadata.audio_urls[0]` 写入唯一上传音频地址。
- 新增 `minimax-h3-ow-t2v-fast`：提示词必填，图片、视频和音频素材均在付费提交前拒绝。
- 三个模型均支持 5/10/15 秒、480p/720p，以及 1:1、2:3、3:2、3:4、4:3、9:16、16:9、21:9 八种比例。
- 前端动态素材 UI、运行前校验和后端 Provider 使用同一份合同；非法素材组合不会发起付费任务。

## 工作流与兼容

- 新增三份无密钥工作流，分别覆盖 REF2VA Audio Drive Fast、FL2VA Audio Drive Fast 和 T2V Fast。
- 继续复用贞贞的平价 AI 小屋既有渠道与凭据；Hailuo TAB、旧模型、默认模型、默认渠道及旧画布显式值均不迁移、不回退。
- API Key、taskId、签名 URL 和原始 Provider 响应不进入源码、工作流、设置、发布说明或脱敏报告。

## 验证

- 模型目录、UI、前后端付费前约束、音频 URL 映射、三份工作流及相邻 seedance.nz 回归 85/85 通过。
- TypeScript、2,863 模块生产构建、公开源码、RH Toolbox、JSON 与能力同步通过；能力目录为 31 actions、250 runtime entries、77/77 nodes、0 public gaps。
