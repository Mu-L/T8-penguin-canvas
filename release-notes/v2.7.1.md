# T8 Penguin Canvas v2.7.1

本版集中修复 Creator Agent 的阶段推进与建议时序，并从共同网络入口解决部分用户在 LLM/Vision、图像、视频、音频和 RunningHub 生成链路中遇到的代理、TUN、VPN 或 IPv6 连接失败。

## Creator Agent 分阶段创作

- Creator Agent 以 `创意 → 剧本 → 资产 → 分镜 → 生成 → 成片` 为权威阶段，每轮只推进一个当前决策，并提供同一决策的三个可编辑选项。
- 三个推荐项只会在本轮流式回复真正完成、SuggestionSet 与当前会话摘要一致后出现；思考中、请求提交中和阶段确认期间不会提前显示旧建议。
- “确认创意，进入剧本”继续严格核对当前创作稿和决策文档，但不会再被画布自动保存、选区或素材摘要等无关变化误判为过期。
- 图像、音频、文本和视频候选使用各自真实结果与质量门槛，不再用视频专属条件阻断其他创作类型。

## 图像与 Story 默认模型

- 普通图像节点及 Story 的“贞贞 AI 工坊（海外）”默认模型统一为 `gpt-image-2`。
- Story 的“贞贞的平价AI小屋”补齐并默认使用 `zhenzhen-image-g-v2-lowprice`。
- 已保存工作流中的有效模型选择继续保留，不做强制迁移。

## Provider 系统网络兼容

- 纠正 v2.7.0 首次 Provider 请求被自建连接池强制接管的共同回归。首次请求重新使用运行时原生系统网络，兼容用户当前的系统代理、TUN、VPN、IPv4 和 IPv6 路径。
- 首次连接失败后才启用禁用旧连接复用的全新系统 DNS 连接；错误提示会返回安全的实际网络原因，不再无依据断言用户切换了代理。
- LLM/Vision 的 JSON 与 SSE、图像、视频、音频、3D、RunningHub 及贞贞的平价AI小屋使用一致的恢复原则。
- 写请求只有在具备稳定提交标识、请求体可安全重放时才恢复，并始终复用相同的 `Idempotency-Key`，避免重复生成和重复扣费。
- 已完成异步任务若在状态响应或结果读取阶段短暂中断，会继续查询并保存原 taskId，不重新提交生成任务。

## 发布边界
