# T8 Penguin Canvas v2.8.7

本版更新现有视频节点的 Hailuo TAB，新增两个 MiniMax H3 OW Fast 模型，并按最新版官方协议刷新国内 Hailuo H3 的 768P/2K 行为。默认视频模型、默认渠道、旧节点、已保存画布显式参数及既有 Provider 协议保持不变。

## MiniMax H3 OW Fast

- 新增 `minimax-h3-ow-i2v-fast`：支持 5/10/15 秒、480p/720p 和八种固定比例，必须且只能输入一张首帧图，提示词可选。
- 新增 `minimax-h3-ow-r2v-fast`：使用相同的时长、分辨率与比例，提示词必填，按画布顺序完整接收 1–9 张参考图，不静默截断为一张。
- 两个 Fast 模型都在付费提交前拒绝视频和音频参考；前后端共同校验模型、素材数量和全部枚举。
- 新增两份无密钥工作流，并通过现有 Video 节点的来源恢复、停止、重试和本地落盘链路运行。

## 国内 Hailuo H3 刷新

- `hailuo-h3-t2v`、`hailuo-h3-i2v`、`hailuo-h3-multi` 均继续支持 768P 与 2K。
- 新建选择、模型切换、请求缺省与三份刷新工作流改用 768P；旧画布显式保存的 2K 原样保留，不迁移或重写。
- T2V、首尾帧 I2V，以及最多 9 图 / 3 视频 / 3 音频 Multi 的既有合同不回退。

## 验证与证据边界

- 模型目录、前端边界、Provider 请求、非法素材、来源恢复、MV/Flux3 相邻能力和既有 Qwen/MiniMax 工作流回归 120/120 通过；最终定向发布回归、TypeScript、公开源码、RH Toolbox、能力目录与生产构建必须在固定源码提交前再次通过。
- 能力目录当前为 31 actions、240 runtime entries、76/76 nodes、0 public gaps；五份工作流均为合法 JSON 且不保存 API Key。
- 真实 Provider 已完成 `minimax-h3-ow-r2v-fast` 的 480p/5 秒端到端验证，结果下载并由 ffprobe 解码为 864×480、H.264、5.166667 秒。Fast I2V 提交返回无 taskId 的 HTTP 502，按防重复扣费边界未自动重放；国内 H3 T2V 在创建 taskId 前因额度不足被拒，H3 I2V/Multi 未继续提交，均不得声称通过。
- 反馈用户安装环境、Fast I2V 与额度阻断的国内 H3 剩余真实 Provider 质量、协作多端及安装升级证据按用户明确授权在发布后补录，仅允许精确 `owner-approved-post-release-v2.8.7` 对完全缺失的证据清单延期；延期不会标记为通过。
