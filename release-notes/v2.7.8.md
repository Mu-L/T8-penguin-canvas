# T8 Penguin Canvas v2.7.8

本版新增完整白模预演工作台、RH 智能翻译能力和 MiniMax H3 镜头数量控制，让白模构图、运镜参考、文本翻译和分镜提示词可以在同一无限画布内持续编辑与复用。

## 白模预演

- 新增 `previs-studio` 节点，完整接入人物、基础几何体、外部 GLB/GLTF、摄像机、姿态、骨骼、IK、物体/镜头关键帧、时间线、撤销重做与工程导入导出。
- 当前帧可导出 1280×720 PNG 构图参考，动画可导出 5 秒、24 FPS、120 帧 H.264 MP4 运镜参考，并通过标准 `image`、`video`、`text`、`metadata` 端口连接 Seedance 2.0 等下游节点。
- 工作台按需加载并通过 Shadow DOM 隔离样式；工程按节点持久化，导入模型和导出媒体进入 T8 受控文件链路，Run/NodeRun/Attempt 与全局 STOP 均已接通。
- 节点和完整工作台均明确标注出处 `GuiYi-Xi/monoform-previs-studio`，固定参考提交 `77f4bae83eeee550a6f416757231f438155bf674`，并感谢原作者。

## RH 智能翻译

- RH 工具箱正式新增 `text.translate` 能力，统一由 `runRhTextTranslation` 调用 WebApp `2084616885802463233`，每次点击只提交一次任务，不自动重放。
- 文本节点、LLM/Vision 用户输入和文本输出素材新增紧凑“译”按钮；中英文自动互译，其他语言默认译为中文，成功结果和脱敏执行记录随画布持久化。
- 翻译期间原文变化时结果标记为 stale 而不覆盖新内容；`@` 素材引用会先保护再恢复，远端丢失引用时失败关闭。

## MiniMax H3 镜头数量

- “镜头数量”新增“自动判断（默认）”和 1–20 个固定镜头选项，旧画布继续保持 AUTO，不改变默认 Provider、模型或请求次数。
- 固定数量同时进入 system 约束和用户参数摘要，要求 `[Shot 1]` 到 `[Shot N]` 连续且各出现一次，并约束后续时间码严格递增且小于目标时长。
