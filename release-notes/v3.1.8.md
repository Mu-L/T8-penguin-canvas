# T8 Penguin Canvas v3.1.8

本版完整保留 v3.1.7 及更早全部节点、模型、工作流、Provider 协议、默认渠道、默认值和旧画布数据，集中修复 VPN/TUN 环境下 Provider 已经生成成功、结果下载却被 Fake-IP 误判为内网，以及刷新或重启后终端日志显示 0 的问题。

## 更新内容

- 所有当前及未来 Provider 的受信结果域名统一交给 Electron/Chromium 处理 DNS、PAC、系统代理、TUN 与 VPN；连接前不再按 `resolveHost` 返回的地址族、公网/私网类别或固定 Fake-IP 网段否决，因此 Mihomo/Clash/sing-box 更换 IPv4 或 IPv6 合成网段也不会再次触发同类误杀。
- Chromium 系统网络临时失败或桥接不可用时，同一 Provider 结果的幂等 GET 回退接受域名解析出的任意有效 IPv4/IPv6 地址。每次重定向仍拒绝字面量本机/内网地址、本地域名和单标签主机，并继续执行跨域凭据剥离、字节/格式校验与生成 POST 不重放。
- 终端日志保存最近 300 条、最长 14 天的恢复副本，刷新或重启后立即恢复；持久副本自动移除签名 URL 查询参数、Bearer/API Key、Token/Secret 等凭据并截断异常长文本，“清空日志”同时清除恢复副本。
- v3.1.7 的媒体生成最低 15 分钟与 LLM 最长 3 分钟合同继续生效；本版不改变模型、渠道、付费提交、轮询身份或旧画布行为。

## 验证与证据边界

- 受信 Provider 下载、普通 URL 安全边界、重定向、Fake-IP、流式落盘与日志恢复/脱敏专项 34/34 通过；TypeScript、能力同步、双语、公开边界、RH 工具箱、Electron 打包和自动更新发布门由正式发布链继续校验。
- Windows 安装包、blockmap 与 `latest.yml` 只由本机唯一一次正式链生成并完整回下载校验。macOS Apple Silicon 在 GitHub Actions 额度可用时从同一不可变 `v3.1.8` Tag 构建 DMG、ZIP 与 `latest-mac.yml`；当前仍为 ad-hoc 完整性签名、未使用 Apple Developer ID、未公证技术预览。
- 真实受影响 VPN/TUN 用户、用户旧库、安装升级/卸载、断电、外部设备、多端协作与 F8–F10 按 `owner-approved-post-release-v3.1.8` 后补；延期不等于通过，正式技术门、固定 Tag/target、Windows 自动更新资产与远端完整性验证不可延期。
