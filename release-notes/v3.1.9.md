# T8 Penguin Canvas v3.1.9

完整继承 v3.1.8 及更早的节点、模型、Provider 协议、默认渠道、超时策略、VPN/TUN 下载兼容、终端日志恢复和旧画布数据。

## 更新内容 / Changes

- 修复 Creator 服务渠道选择时，函数式状态更新读取已结束 React 事件导致的 `Cannot read properties of null (reading 'value')` 崩溃。现在同步捕获选择值，延迟/重放更新不再依赖事件；原三类模型重置和其他设置保留。
- Fix the Creator provider selector's delayed state updater reading an expired React event. Capture the selected value synchronously, preserve unrelated settings, and retain the existing model-reset behavior.
- 新增执行真实生产 JSX 处理器的回归，覆盖事件清空、连续切换和状态更新重放；对齐既有 Creator UI 与 Electron i18n 测试，不回退产品行为。
- Add production-handler regressions for event cleanup, rapid selections and updater replay, and align existing Creator UI / Electron i18n tests without reverting product behavior.
