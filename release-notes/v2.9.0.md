# T8 Penguin Canvas v2.9.0

本版为“贞贞的平价 AI 小屋”补充最新图像与音频模型，并为每个模型保存可直接导入的无密钥工作流。既有默认渠道、默认模型、历史节点、已保存画布字段以及 v2.8.9 和更早版本的全部能力保持不变。

## 图像模型

- Grok 现有 TAB 新增 `zhenzhen-image-gk-v2`，支持文生图、参考图、1–10 张输出以及模型对应的画幅比例。
- 图像节点新增 Wan Image TAB，包含 `wan-2.7-global-t2i`、`wan-2.7-global-i2i` 和 `wan-2.7-global-i2i-pro`。
- Wan 文生图支持 512–4096 自定义宽高与 thinking；I2I/I2I Pro 按画布顺序接收 1–9 张参考图，不静默截断。

## 音频模型

- 音频节点新增 Qwen3-TTS TAB：`qwen3-tts-flash`、`qwen3-tts-instruct-flash`。
- 新增 MiniMax TAB：`minimax-music-2.6`、`minimax-speech-2.8-hd`、`minimax-speech-2.8-turbo`、`minimax-voice-clone`。
- 新增 Mureka TAB：`mureka-v8-bgm`、`mureka-v9-bgm`。
- Mureka 的 `n=1–3` 多音频结果会严格按 Provider 原始顺序全部下载、持久化并传给下游，不排序、不去重、不截断。
- MiniMax 声音克隆只接受一段参考音频与合法自定义音色 ID，完整支持音频、文本音色结果或两者同时返回。
