# T8 Penguin Canvas v2.7.2

本版集中修复 RunningHub AI 应用返回文本结果时画布无限轮询、任务已完成却迟迟不出结果的问题，并保持图像、视频、音频等既有媒体结果链路不变。

## RunningHub 文本结果终态

- RunningHub 查询现在会结合 `fileType`、MIME 和签名 URL 扩展名识别 TXT、Markdown、JSON 与 CSV，不再把文本产物送入图像/视频/音频魔数校验。
- 文本使用有界安全下载读取并统一持久化为本地 UTF-8 文件；纯文本和文本 + 媒体混合任务会在同一次 `SUCCESS` 响应返回。
- 普通 RunningHub 节点、RH AI 应用节点和 RH 工具箱统一接收 `texts` / `textUrls`，同步写入 `outputText`、`text`、`texts` 与 `textSegments`，可继续沿画布连线传给下游。
- 已完成的 taskId 只查询并转存原结果，不重新提交任务，不会造成重复生成或重复扣费。
