# T8 Penguin Canvas v3.2.2

## 磁盘空间提示与数据目录迁移

- 空间不足提示显示实际盘符、当前剩余 GiB 和动态计算的最低预留 GiB，不再只显示 schema32 内部备份术语。建议应用数据盘预留 10 GiB。
- 安装版设置页及画布加载失败页新增“选择其他盘并迁移重启”，可将画布数据库、备份、配置、输入/输出素材、缩略图和语义模型迁移到 D/E 等盘的新独立目录。
- 保存与任务关闭保护通过后重启，在数据库打开前离线复制，逐文件 SHA-256 与源目录一致性校验、落盘完成后切换路径；原目录不自动删除。中断副本不会当成完整数据，已有目标不覆盖，断开的数据盘不会被空目录替代。启动窗口显示复制/校验进度。
- Electron 登录与浏览器配置仍保留在原 profile；系统临时目录所在盘仍需至少 0.5 GiB。自定义导出路径和第三方目录不会擅自迁移。

## 兼容与验证边界

- 保留 v3.2.1 及更早节点、模型、默认值、Provider、工作流、已有画布和 schema32 恢复保护；不降低安全空间门，不自动回滚数据库。
- 迁移临时夹具、容量 SQLite、Electron 依赖/关闭/发布门和类型检查等本地证据见 `docs/desktop-data-storage.md` 与 `docs/release-v3.2.2.md`。正式包、更新清单、固定源码和完整回下载以发布脚本实际结果为准。
- 真实用户旧库、安装升级、跨物理盘、大容量掉电和 F8–F10 证据按 `owner-approved-post-release-v3.2.2` 后补，不记通过。Windows 正式构建与自动更新不可延期；Mac 仅在 GitHub 额度不足时延期，未公证版本继续标明技术预览。
