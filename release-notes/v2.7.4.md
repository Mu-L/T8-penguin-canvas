# T8 Penguin Canvas v2.7.4

本版从根因修复 Electron 桌面端在系统代理、TUN、VPN、IPv4/IPv6 环境下的 Provider 连接与已完成任务结果下载，并修复资源库素材发送、拖入空白画布及继续作为下游节点上游素材的交互链路。

## 修复

- Electron 普通 HTTP(S) Provider 请求统一优先使用 Chromium 系统网络栈，跟随 Windows 系统代理、TUN、VPN、IPv4/IPv6 与证书环境。
- 网络切换或连接失败时刷新 Chromium 代理配置和 DNS 缓存；GET 只读请求最多自动重试一次，写请求不会自动重放，避免重复生成和重复扣费。
- LLM/Vision、图像、视频、音频、RunningHub、Seedance 及可信 Provider 状态/结果下载复用同一兼容层，不再只覆盖单个图像模型。
- 可信远程结果继续执行跨域敏感头剥离、响应大小上限、回环/内网拒绝、TUN RFC2544 Fake-IP、NAT64、DNS 固定回退与部分流清理。
- 修复资源库加号或飞机发送后只关闭抽屉、没有在画布生成素材节点的问题。
- 修复 Ctrl 拖拽资源到空白画布在 Chromium 指针事件环境中失效的问题；新增 pointermove、pointerup、pointercancel 并保留鼠标回退。
- 资源库进入画布后保留原始文件名、MIME、字节数和资源引用，图片、视频、音频可继续作为生成节点上游素材。

## 验证

- 系统网络桥接、可信 Provider 输出、安全远程素材、代理日志、Seedance 媒体与资源库入画布/上游素材聚焦回归 121/121 通过。
- 覆盖系统网络健康请求、GET 恢复、写请求不重放、显式 dispatcher/流式 body Node 回退、跨域重定向、大小限制、回环拒绝、TUN Fake-IP、NAT64 与部分流清理。
- TypeScript、能力目录、公开发布面、RH 工具箱及 Electron 正式发布门由固定发布提交上的唯一一次正式流程验证。

## 发布边界

- 本次正式 Electron / NSIS 包只构建一次，并限制构建并行度，不执行 FFmpeg 转码压力任务。
- 用户已明确授权先发布，后补真实 Provider、协作多端与安装升级证据；延期项目不会提前标记为通过。
