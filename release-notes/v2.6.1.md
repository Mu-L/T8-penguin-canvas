# 贞贞的无限画布 v2.6.1

本版新增贞贞平价 AI 小屋的图像、视频与超分模型，并让已经生成过素材的工作流可以安全复用现有结果继续执行下游。

## 贞贞图像与视频模型

- 图像节点 GPT2 TAB 新增 `zhenzhen-image-g2-t2i` 与 `zhenzhen-image-g2-i2i`，使用独立平价 AI 小屋 Key、异步任务协议和安全本地转存；图生图严格限制 1–10 张参考图。
- 视频节点新增 Hailuo TAB，接入 Hailuo 2.3 文生/图生六个模型；6 秒、768p 的六模型真实任务均已成功验证。
- 视频节点新增 Vidu TAB，接入 Q3 文生、图生、首尾帧、参考生和短剧协议。9 个文生/图生/首尾帧模型真实验证成功；本次上游失败的参考生与短剧模型保持禁用，避免无效计费请求。
- 视频节点新增 Kling TAB，接入 v3.0、v3 Turbo、v3 4K 与 O3 文生/图生/参考生/编辑协议。六个文生模型真实验证成功；其余模型保留实现及真实授权边界，不把本次凭据的 403 误报为全平台不可用。
- 视频节点新增 Upscaler TAB，接入 `zhenzhen-upscaler` 单视频 720p/1080p/2K/4K 高清化；真实 720p 任务已成功验证并安全转存。

## 工作流结果复用

- 图像/编辑、视频、SD2.0、音频、RunningHub、RH 钱包、RH 超市与 RH 工具箱生成节点新增默认关闭的“复用结果”。
- 开启后，仅当节点已有匹配输出类型的真实素材时跳过 Provider/ffmpeg 执行，并继续调度连线下游；没有有效结果时仍会正常生成。
- 复用仍保留 Run、NodeRun、Attempt、输出和成功终态证据，但不会伪造 Provider 请求、提交或响应事件。

## 发布与验证边界

- 版本由 `package.json` 统一注入 Web、Electron 与后端；公开源码继续排除 `local-private/**`、私有扩展实现、测试 Key、缓存、外部参考项目和维护者文档。
- 正式自动更新资产包含 Windows x64 NSIS 安装包、对应 blockmap 与 `latest.yml`，正式包只构建一次。
- F8–F10 的双设备、三个隔离客户端、公共 HTTPS/TLS/SNI、红队与负载证据仍未补齐。按用户 2026-07-21 的再次明确授权，v2.6.1 仅在证据清单完全不存在且绑定固定 source commit 时使用一次性“先发布、后补证据”延期；这不代表任何外部证据检查已通过。
