# 贞贞的无限画布 v2.6.0

本版整合多人协作 F2-F7、运行与存储加固，并集中修复会打断创作的执行确认、节点输出、VibeX 和 Photoshop 联动问题。

## 多人协作与审片

- 补齐断线重连、指数退避、增量同步与离线操作恢复，过期 revision 和迟到结果保持失败关闭。
- 结构操作并发、协同文本冲突与撤销、删除/编辑竞争均使用权威 revision 和审计证据处理。
- 素材上传支持断点续传、ACL 与配额约束；评论、回复、审批和审片状态纳入角色能力边界。
- 运行请求进入权威队列，Run、NodeRun、Attempt、重放与审计记录保持同一身份，旧执行不能串写新运行。

## 运行、存储与安全

- 普通 RUN 仍执行只读体检和最终重验，但 `cost.unknown` 等 advisory 警告不再每次弹出确认窗口；结构、能力、素材、策略 blocker 以及高风险远程运行仍要求明确确认。
- 数据库 schema 32 增加物理容量准入、canonical backup freshness receipt、精确迁移 lineage 和故障恢复约束；全节点运行事件与权限清单继续失败关闭。
- 公网自检、分级限速、证据清单、私有接口扫描和发布闸门已接入；真实双设备、公网 TLS/SNI、红队与负载证据仍必须在正式发布前独立采集，不能由本机测试替代。

## 创作体验修复

- 图像与编辑节点新增默认开启的“仅输出图片结果（不输出 Prompt）”，旧画布缺字段也按开启处理；取消勾选可恢复原有图文输出。
- 第三方视频 Provider 返回结构化错误对象时会提取安全文本，不再触发 React error #31 和整张画布错误边界。
- VibeX 内嵌页面的下拉菜单可正常使用滚轮和拖动滚动条，菜单内部滚动不会立即收起。
- Photoshop Link 升级到 0.1.4：编辑模式始终读取当前活动图层，补强颜色/位深转换、临时文档清理、请求快照和紧凑面板滚动；安装包只携带权威插件目录并校验逐文件摘要。

## 发布与验证边界

- 版本来源统一由 `package.json` 注入前端、Electron 与后端；公开源码继续排除本地私有扩展、缓存、外部项目和维护者文件。
- 候选聚焦回归 52/52、完整 TS 回归 195 个文件四组全部通过；type-check、公开源码扫描、RH 工具箱、JSON/脚本语法、工作树角色与差异检查通过。集成提交此前已按正确 ABI 覆盖 193 个 TS 与 186 个 CJS 文件共 2872 项（2865 通过、7 条件跳过）。
- 正式自动更新交付预计包含 Windows x64 NSIS 安装包、对应 blockmap 与 `latest.yml`。
- 正式包只允许构建一次；构建前必须先把公开源码提交推送到 `origin/main`，再提交与该 40 位源码 SHA 精确绑定的 `t8-collaboration-release-evidence-v2` 真实验收清单。
