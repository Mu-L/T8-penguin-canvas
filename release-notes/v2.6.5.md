# 贞贞的无限画布 v2.6.5

本版集中处理代理、TUN、VPN 和 Fake-IP 环境下“任务完成但结果无法下载”的问题，并补齐工作流医生开关、RunningHub 站点显示，以及 LLM / Story 的贞贞平价 AI 小屋模型线路。

## TUN、VPN 与生成结果下载

- 图片、视频、音频和 3D 等生成链路统一接入安全远程素材下载；遇到 TUN Fake-IP 时，通过独立公共 DNS 查询真实公网地址后继续下载，不要求用户关闭代理。
- 公网回源不会放宽 SSRF 边界：本机、内网、链接文件、错误 MIME、超限响应和重定向异常仍会阻断。
- 代理、TUN 或 VPN 切换后会刷新 Provider 连接池；GET/HEAD 查询可安全重试一次，可能重复扣费的生成提交不会自动重发。
- 节点和终端日志会返回更明确的 DNS、代理、TLS、超时、HTTP、磁盘空间、输出目录权限或上游空结果原因；已经完成的 Provider 任务保留并继续转存，不会重新提交生成。
- Photoshop、VibeX、RunningHub、RH、FAL、Seedance 及通用 Provider 的远程结果采用同一下载原则。

## 工作流医生与 RunningHub

- 左侧画布工具栏新增工作流医生开关，默认关闭并持久保存；关闭时不再强制弹出诊断或阻断创作。
- 医生关闭后仍保留运行范围推导、画布 revision、一致性和并发安全检查，避免绕开执行契约。
- RunningHub 节点会根据 WebApp 的实际解析站点更新显示，海外 `runninghub.ai` 不再错误显示为国内 `runninghub.cn`。
- RH 工具箱制作器的站点枚举由 `cn / intl` 调整为 `cn / ai`，其余工具定义与调用契约保持不变。

## LLM / Vision 与 Story

- LLM / Vision 默认来源更名为“贞贞的AI工坊-独立LLM Key(默认)”。
- 新增“贞贞的平价AI小屋”，模型只使用 API 文档锁定的 20 个选项，支持普通响应和 SSE 流式输出。
- Story 原“贞贞内置 LLM”更名为“贞贞AI工坊内置LLM”，第二项新增“贞贞的平价AI小屋”。
- Story 保存所选语言平台、模型和对应 Key 线路；剧本分析及一次格式修复沿用同一线路，后续资产与视频阶段不会误报语言 Key 缺失。

## 发布与验证边界

- 平价 AI 小屋模型目录、非流式和 SSE 请求已使用维护者提供的测试 Key 实测成功；Key 未写入源码、配置、日志或发布资产。
- 发布前执行专项合同测试、TypeScript、公开源码、RH 清单、生产构建、加密后端、私有 sidecar、运行时归档与 Electron post-build 门禁。
- Electron/NSIS 正式打包只触发一次；不执行 FFmpeg 视频转码或额外冷启动压力测试。
- F8–F10 的真实双设备、三个隔离客户端、公共 HTTPS/TLS/SNI、红队与负载证据仍待补。按用户 2026-07-24 的明确授权，v2.6.5 只在证据清单完全不存在且绑定固定 40 位 source commit 时使用 `owner-approved-post-release-v2.6.5` 一次性延期；延期不会把任何证据检查标记为通过。
