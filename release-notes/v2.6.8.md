# T8 Penguin Canvas v2.6.8

本版把常用图片微调、素材尺寸控制和“贞贞的平价AI小屋”创作能力集中到节点内，减少反复切换工具和记忆模型参数的成本。

## 主要更新

- 图像节点新增“图像调节助手”，提供 12 类 × 20 项共 240 项高质量原子调节，覆盖人景融合、光影、皮肤、材质、清晰度、构图、色彩、镜头、参考一致性、结构修复、氛围和动态。
- 调节助手支持搜索、同类替换、跨类组合、冲突处理、撤销与清空；不会覆盖用户原 Prompt、上游文本或 `@` 素材引用，也不会额外调用模型。
- 上传图像与输出素材图像区新增 1K / 2K 长边按钮，按 1024 / 2048 像素等比缩小后再向下游传递；不会放大小图，不改变宽高比。
- 画布缩小时移除会导致 Chromium 位图重采样的节点滤镜，并在缩放结束后按设备像素对齐视口，改善小字发糊。
- 图像节点 MJ TAB 在“贞贞的平价AI小屋”新增 16 项 Midjourney 动作：Imagine、Blend、Describe、Edits、Upscale、Variation、High/Low Variation、Reroll、Zoom、Pan、Inpaint、Modal、Video、Remix Strong/Subtle。
- 音频节点 Suno TAB 新增“贞贞的平价AI小屋”平台，提供官方 31 项生成、歌词、上传、续写、翻唱、混音、分轨、母带、MIDI、BPM、Persona、采样和编辑动作。

## 兼容与安全

- 原“贞贞AI工坊”Midjourney 与 Suno 接口、API Key、默认模型和旧画布数据保持不变；两套平台独立调用，互不串线。
- Midjourney 与 Suno 使用显式动作白名单和按动作字段校验，结果只有在完成本地安全转存后才返回节点。
- 1K / 2K 缩放使用本地 Sharp 处理；JPEG 使用最高质量 4:4:4，WebP 使用无损模式，PNG 保持无损。
- Canvas Agent / zcanvas 仍为本地实验，不包含在 v2.6.8 公开源码和安装包中。
- 用户已明确授权先发布、后补真实 Provider、协作及安装包完整回下载证据；延期不会把缺失证据标记为通过。
