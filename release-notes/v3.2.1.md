# T8 Penguin Canvas v3.2.1

## 画布恢复修复

- 修复 schema32 主数据库无法读取时，完整可验证的同库 canonical backup 因写入水位落后或恢复代次不同而让画布一直无法加载的问题。
- 受影响画布保持只读，并显示恢复旧备份可能舍弃的已确认数据库写入次数。用户明确确认后，程序使用十分钟内的一次性方案恢复，并保留故障主库证据。
- 恢复严格复核数据库 UUID、备份收据、ACK 摘要、代次与写入水位；恢复后的 ACK 继续向前。身份不符、备份不可验证、方案过期或被篡改时仍拒绝操作。

## 兼容与验证边界

- 完整保留 v3.2.0 及更早节点、模型、默认值、Provider、工作流与现有画布。无法从已经丢失的主库/WAL 页面重建最近写入；旧备份恢复前会明确提示潜在差额。
- schema32、相邻回归与真实 HTTP 确认流程 47/47、TypeScript、公开源码、能力同步和开发态生产构建已通过。正式 Electron、NSIS、自动更新与远端完整下载以发布脚本实际结果为准。
- 受影响用户旧库、真实安装升级、外部设备及 F8–F10 证据按 `owner-approved-post-release-v3.2.1` 后补，不记为通过。Windows 正式构建、固定 Tag/源码、自动更新资产及远端完整性不可延期；Mac 仅在 GitHub Actions 额度不足时可延期。
